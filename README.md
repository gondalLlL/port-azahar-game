# Port Azahar

**Port Azahar** is an original top-down 2D open-world crime game built for the make.fun gta6-01 competition. Follow protagonist Dario Venn as he runs jobs for fixer Marisol Kane across five distinct districts: Docks, Neon Mile, Old Town, Marina, and The Hills.

## Features
- **Open World & Districts**: Explore a massive 40x40 city grid with varied architectural palettes, neon signs, parks, and coastal waterfronts.
- **On Foot & Driving**: Switch seamlessly between walking/sprinting on foot and driving cars (enter/exit with E or F) with speed-sensitive steering and physics.
- **Combat & Wanted System**: Engage in melee combat, shoot with your pistol, and evade up to 5 stars of police pursuit AI.
- **Mission Chain**: Complete 5 action-packed missions with dialogue banners, time limits, and objectives.
- **Synthesized Audio**: Dynamic WebAudio sound effects (engine hum, sirens, gunshots) without external assets.

## Run It

To run the game locally:
```bash
node serve.ts
```
Then open your browser at:
`http://localhost:8080`
